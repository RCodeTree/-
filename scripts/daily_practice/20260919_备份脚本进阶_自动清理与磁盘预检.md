# 每日 Shell 运维实战练习 · 2026-09-19

## 题目：备份脚本进阶——磁盘空间预检 + 自动清理旧备份

### 题目背景

昨天你写好了 `backup.sh`，实现了"临时文件 + 原子改名"的可靠备份。但生产环境中，一个备份脚本如果只"写"不"管"，很快会遇到两个问题：

1. **备份盘写满**：备份前不检查磁盘剩余空间，一旦分区写满，备份会中途失败并留下脏数据，甚至拖垮整个分区。
2. **旧备份堆积**：每天备份一份，几个月后磁盘被大量过期备份占满，只能靠人工清理。

今天在昨天 `backup.sh` 的基础上，给它加三个能力：**磁盘空间预检、保留最近 N 份自动清理、日志落盘**。

> ⚠️ 注意：清理旧备份涉及"删除"，属于破坏性操作。请务必先在临时目录里放几个**假的备份文件**验证删除逻辑，确认只会删本脚本产物、不会误删其它文件后，再用于真实数据。

---

## 脚本编写要求

在昨天 `backup.sh` 的基础上改造，新增：

1. **选项解析**：支持 `-k N`（`--keep` 简写）指定"只保留最近 N 份备份"，`N` 为正整数；不传 `-k` 时**不清理**旧备份。用 `getopts` + `case` 实现，并支持 `-h` 打印用法。
2. **磁盘空间预检**：打包前用 `df` 检查备份目录所在分区的使用率，超过阈值（如 ≥ 90%）时报错退出，**不执行打包**。
3. **自动清理旧备份**：备份成功后，若指定了 `-k N`，删除该源目录对应的旧备份，只保留最近 N 份（按文件修改时间倒序）。**只删本脚本生成的 `${BASE_NAME}_*.tar.gz`**，绝不能误删同目录下的其它文件。
4. **日志落盘**：所有日志同时输出到终端和日志文件（如 `/var/log/backup.log`），用 `tee -a` 追加，便于事后审计。

## 考察知识点

- `getopts` 与 `case` 处理命令行选项、`shift` 让位置参数归位
- `df --output=pcent` 磁盘使用率检查、`tr -d` 清理空格/百分号、算术比较 `-ge`
- `find -printf '%T@ %p'` 按修改时间输出、`sort -rn` 倒序、`tail -n +N` 跳过最新 N 个
- 破坏性操作（删除）前的**范围收窄**（只删本脚本产物）与安全验证
- `tee -a` 日志落盘、`[[ =~ ]]` 正则校验参数合法性

---

## 验收标准

1. 不传参数或传错参数（如 `-k abc`）时，能打印用法并退出码为 `2`。
2. 传 `-k 3` 后连续备份 5 次，目录里最终只保留**最新 3 份**备份。
3. 备份盘使用率超过阈值时，脚本报错退出且**不生成任何备份文件**。
4. 清理逻辑只删除 `${BASE_NAME}_*.tar.gz`，同目录下一个无关文件（如 `keep.txt`）不受影响。
5. 日志文件 `/var/log/backup.log` 里能看到与终端一致的完整日志。

## 参考答案（写完后对照）

```bash
#!/bin/bash
set -euo pipefail

# ==================== 日志（终端 + 文件） ====================
LOG_FILE="/var/log/backup.log"
log_info()  { echo -e "\033[32m[INFO]  $(date '+%F %T') $*\033[0m" | tee -a "$LOG_FILE"; }
log_warn()  { echo -e "\033[33m[WARN]  $(date '+%F %T') $*\033[0m" | tee -a "$LOG_FILE"; }
log_error() { echo -e "\033[31m[ERROR] $(date '+%F %T') $*\033[0m" | tee -a "$LOG_FILE" >&2; }

# ==================== 全局变量 ====================
TMPFILE=""
KEEP=""          # 保留最近 N 份；空表示不清理
MIN_USE_PCT=90   # 备份盘使用率阈值（%）

clean_up() {
    if [[ -n "$TMPFILE" && -f "$TMPFILE" ]]; then
        rm -f "$TMPFILE"
        log_warn "已清理未完成的临时文件: $TMPFILE"
    fi
}
trap clean_up EXIT
trap 'exit 130' INT
trap 'exit 143' TERM

# ==================== 用法 ====================
usage() {
    log_error "用法: $0 [-k 保留份数] <源目录> <备份目录>"
    log_error "示例: $0 -k 7 /var/www/html /backup"
}

# ==================== 选项解析 ====================
while getopts "k:h" opt; do
    case "$opt" in
        k)
            KEEP="$OPTARG"
            if ! [[ "$KEEP" =~ ^[0-9]+$ ]] || [ "$KEEP" -lt 1 ]; then
                log_error "错误: -k 需要正整数"
                exit 2
            fi
            ;;
        h)
            usage
            exit 0
            ;;
        ?)
            usage
            exit 2
            ;;
    esac
done
shift $((OPTIND - 1))

# ==================== 参数校验 ====================
if [ $# -ne 2 ]; then
    usage
    exit 2
fi

SRC_DIR="$1"
BACKUP_DIR="$2"

if [ ! -d "$SRC_DIR" ]; then
    log_error "源目录不存在或不是目录: $SRC_DIR"
    exit 1
fi
if [ ! -r "$SRC_DIR" ]; then
    log_error "源目录不可读: $SRC_DIR"
    exit 1
fi
if ! mkdir -p "$BACKUP_DIR"; then
    log_error "无法创建备份目录: $BACKUP_DIR"
    exit 1
fi

# ==================== 磁盘空间预检 ====================
USE_PCT=$(df --output=pcent "$BACKUP_DIR" | tail -1 | tr -d ' %')
if ! [[ "$USE_PCT" =~ ^[0-9]+$ ]]; then
    log_error "无法解析备份盘使用率: $BACKUP_DIR"
    exit 1
fi
if [ "$USE_PCT" -ge "$MIN_USE_PCT" ]; then
    log_error "备份盘使用率已达 ${USE_PCT}%，空间不足，中止备份"
    exit 1
fi
log_info "备份盘剩余空间充足（使用率 ${USE_PCT}%）"

# ==================== 生成文件名 ====================
STAMP=$(date '+%Y%m%d_%H%M%S')
BASE_NAME=$(basename "$SRC_DIR")
FINAL_FILE="${BACKUP_DIR}/${BASE_NAME}_${STAMP}.tar.gz"
TMPFILE=$(mktemp "${BACKUP_DIR}/.backup_${BASE_NAME}.XXXXXX")

log_info "开始备份: $SRC_DIR -> $FINAL_FILE"

# ==================== 打包 + 校验 + 原子改名 ====================
if ! tar -czf "$TMPFILE" -C "$(dirname "$SRC_DIR")" "$BASE_NAME"; then
    log_error "打包失败: $SRC_DIR"
    exit 1
fi
if [ ! -s "$TMPFILE" ]; then
    log_error "备份失败：生成的压缩包为空"
    exit 1
fi
if ! tar -tzf "$TMPFILE" >/dev/null 2>&1; then
    log_error "备份失败：压缩包校验未通过"
    exit 1
fi

mv "$TMPFILE" "$FINAL_FILE"
TMPFILE=""

SIZE=$(du -h "$FINAL_FILE" | cut -f1)
log_info "备份完成: $FINAL_FILE (大小: $SIZE)"

# ==================== 清理旧备份 ====================
if [ -n "$KEEP" ]; then
    find "$BACKUP_DIR" -maxdepth 1 -type f -name "${BASE_NAME}_*.tar.gz" -printf '%T@ %p\n' \
        | sort -rn \
        | tail -n +$((KEEP + 1)) \
        | cut -d' ' -f2- \
        | while IFS= read -r old_file; do
              rm -f "$old_file"
              log_info "已清理旧备份: $old_file"
          done
fi
```

## 关键点讲解与运维最佳实践

1. **`getopts` 为什么比手工解析 `$1` 更可靠？**
   `getopts` 能正确处理 `-k 3`、`-k3`、选项和位置参数混排（如 `./backup.sh -k 3 /a /b`）等情况，并自动处理非法选项（返回 `?`）。`shift $((OPTIND - 1))` 把已解析的选项从参数列表里"移走"，之后 `$1`、`$2` 才是纯位置参数（源目录、备份目录）。

2. **磁盘预检放在"打包之前"是红线。**
   如果先打包、写了一半才发现磁盘满了，会留下脏数据。所以 `df` 检查必须**在任何写盘动作之前**。`df --output=pcent` 直接取"使用率"列，比 `df -h` 再 `awk` 解析更稳；`tr -d ' %'` 清掉空格和 `%`，剩下纯数字，再用 `[[ =~ ^[0-9]+$ ]]` 兜底校验（某些文件系统会返回 `-`）。

3. **清理旧备份的"范围收窄"是安全核心。**
   用 `find ... -name "${BASE_NAME}_*.tar.gz"` 明确限定"只删这个源目录对应的备份文件"，而不是 `rm -rf "$BACKUP_DIR"/*`。`-printf '%T@ %p\n'` 输出"修改时间戳 + 路径"，`sort -rn` 按时间倒序（新的在前），`tail -n +$((KEEP+1))` 跳过最新 N 个、只留下"该删的旧文件"。`cut -d' ' -f2-` 取回路径（保留路径中的空格）。

4. **为什么用 `tee -a` 而不是把 `echo` 直接重定向到文件？**
   `echo ... | tee -a file` 能**同时**上屏和追加到文件；`>> file` 只能落盘、终端看不到。`log_error` 里 `tee -a ... >&2` 先让 tee 把内容写进文件，再把它自己的 stdout 重定向到 stderr，从而"错误信息既进日志文件、又走 stderr 流"。

5. **退出码延续昨天的约定：`2` 用法错误、`1` 运行错误、`0` 成功。**
   `getopts` 的 `?` 分支（非法选项）和 `-k` 参数不合法、以及"位置参数个数不对"都属于"用法错误"，统一 `exit 2`，让上层 cron 能区分"参数错了"还是"运行失败了"。

### 进阶提示（下一阶段再扩展）

- 增加 `--delete-source` 之类的开关前，先想想"备份是否已验证可恢复"——**备份的真正意义在于能恢复**，建议再补一个 `--restore` 子命令做恢复演练。
- 清理旧备份时，可加 `--dry-run` 选项：只打印"将要删除哪些文件"而不真删，这是运维脚本里常见的"可观测性"设计。
