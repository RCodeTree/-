# Shell

``` bash
if [ 条件 ]; then
    条件成立时执行
else
    条件不成立时执行
fi
```

``` bash
for [条件]; do
    循环体
done
```

``` bash
while [条件]; do
    循环体
done
```

## 条件判断写法

| 写法 | 含义 |
|------|------|
| `[ -f file ]` | 文件是否存在 |
| `[ -d dir ]` | 目录是否存在 |
| `[ -z "$var" ]` | 变量是否为空 |
| `[ "$a" = "$b" ]` | 字符串相等 |
| `[ $n -gt 100 ]` | 数字大于 100（`-gt` 大于，`-lt` 小于，`-eq` 等于） |
