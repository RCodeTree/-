# Shell

``` bash
if [ 条件 ]; then
    条件成立时执行
else
    条件不成立时执行
fi
```

``` bash
for [条件]; do
    循环体
done
```

``` bash
while [条件]; do
    循环体
done
```

## 条件判断写法

| 写法 | 含义 |
|------|------|
| `[ -e path ]` | 路径是否存在（文件或目录皆可） |
| `[ -f file ]` | 文件是否存在（普通文件） |
| `[ -d dir ]` | 目录是否存在 |
| `[ -r file ]` | 文件是否可读 |
| `[ -w file ]` | 文件是否可写 |
| `[ -x file ]` | 文件是否可执行 |
| `[ -s file ]` | 文件是否存在且非空（大小 > 0） |
| `[ -L file ]` | 是否为符号链接 |
| `[ -z "$var" ]` | 变量是否为空 |
| `[ -n "$var" ]` | 变量是否非空 |
| `[ "$a" = "$b" ]` | 字符串相等 |
| `[ "$a" != "$b" ]` | 字符串不相等 |
| `[ $n -eq 100 ]` | 数字等于 100 |
| `[ $n -ne 100 ]` | 数字不等于 100 |
| `[ $n -gt 100 ]` | 数字大于 100 |
| `[ $n -lt 100 ]` | 数字小于 100 |
| `[ $n -ge 100 ]` | 数字大于等于 100 |
| `[ $n -le 100 ]` | 数字小于等于 100 |

## 三种执行方式的本质区别（⚠️ 重点，面试常考）

同一个脚本，三种跑法结果看着一样，但**底层完全不同**：

| 方式 | 是否子进程 | 是否需要执行权限 | 变量是否影响当前终端 |
|------|-----------|----------------|---------------------|
| `./hello.sh` | ✅ 新开子进程 | ✅ 需要 | ❌ 不影响 |
| `bash hello.sh` | ✅ 新开子进程 | ❌ 不需要 | ❌ 不影响 |
| `source hello.sh` / `. hello.sh` | ❌ 当前 shell | ❌ 不需要 | ✅ **会污染当前终端** |

### 特殊变量（⭐ SRE 核心，务必记住）

| 变量 | 含义 | 典型用途 |
|------|------|---------|
| `$0` | 脚本自身名字 | 打印脚本路径/日志前缀 |
| `$1`~`$9` | 位置参数（第 1~9 个） | 接收用户传入的参数 |
| `$#` | 参数个数 | 校验参数是否传够 |
| `$@` | 所有参数（**每个独立**） | 遍历参数 |
| `$*` | 所有参数（**合并成一个**） | 了解区别即可 |
| `$?` | 上一条命令的退出码 | **判断命令是否成功** |
| `$$` | 当前脚本的进程号 PID | 生成临时文件、日志 |

**`$?` 是重中之重**：`0` 表示上一条命令成功，**非 0 表示失败**。这是脚本判断"接下来该不该继续"的唯一依据。

# Shell 文本处理

## 一、awk 中的数值转换与正则匹配

### 1. `+$5` 是什么意思？

在 awk 中，`+` 作为**一元运算符**放在变量或字段前面，表示**强制将后面的值转换为数值**。

```awk
+$5
```

等价于：

```awk
$5 + 0
```

- `$5` 是第 5 个字段，默认按字符串处理。
- 加上一元 `+` 后，awk 会把它当成数字。
- 如果 `$5` 是 `"90"` → 转换为 `90`
- 如果 `$5` 是 `"80.5"` → 转换为 `80.5`
- 如果 `$5` 是 `"abc"` 或空 → 转换为 `0`

**为什么要这样写？**

直接写 `$5 > 80` 时，如果 `$5` 不是纯数字，awk 可能会按字符串比较，导致意外结果。写成 `+$5 > 80` 就明确告诉 awk：**按数值比较**。

示例：

```awk
awk 'NR>1 && +$5 > 80 {print $1" "$5" "$6}'
```

含义：跳过第 1 行，从第 2 行开始，若第 5 列转成数字后大于 80，则打印第 1、5、6 列，中间用空格分隔。

---

### 2. `=~` 表示什么？

`=~` 通常表示**正则匹配**：判断左边的字符串是否匹配右边的正则表达式。

但要注意：

> **在 awk 中，匹配操作符是 `~`，不是 `=~`。**

#### awk 中的正确写法

```awk
$1 ~ /abc/      # 第 1 列匹配 abc
$1 !~ /abc/     # 第 1 列不匹配 abc
```

示例：

```awk
awk '$1 ~ /^a/ {print}' file
```

表示：第 1 列以 `a` 开头就打印。

如果在 awk 中写成 `$1 =~ /abc/`，通常会报语法错误，因为 awk 没有 `=~` 这个操作符。

#### `=~` 常见于其他环境

- **Bash 的 `[[ ]]`**：
  ```bash
  [[ $str =~ ^abc ]]
  ```
  判断 `$str` 是否匹配正则 `^abc`。

- **Perl**：
  ```perl
  $str =~ /^abc/;
  ```

**总结**：

| 环境 | 匹配操作符 | 不匹配操作符 |
|------|------------|--------------|
| awk  | `~`        | `!~`         |
| Bash `[[ ]]` | `=~` | 无直接对应，可用 `! [[ ... =~ ... ]]` |
| Perl | `=~`       | `!~`         |

## 二、find 命令详解

### 命令示例

```bash
find "$target_dir" -maxdepth 1 -type f -name "${base_name}_*.tar.gz" -printf '%T@ %p\n'
```

### 整体作用

- 在变量 `$target_dir` 指定的目录中查找。
- 只搜索该目录本身，**不进入子目录**（`-maxdepth 1`）。
- 只找普通文件（`-type f`）。
- 文件名匹配 `${base_name}_*.tar.gz`：以 `base_name` 的值开头，接着下划线，然后任意字符，最后 `.tar.gz` 结尾。
- 对每个找到的文件，输出其**最后修改时间的 Unix 时间戳**和**完整路径**，每行一个。

---

### 重点选项 1：`-maxdepth 1`

`-maxdepth` 用于限制 `find` 向下搜索的目录深度。

- 起始目录本身深度为 **0**。
- 起始目录的直接子项（文件或子目录）深度为 **1**。
- 子目录中的内容深度为 **2**，以此类推。

因此：

| 写法 | 含义 |
|------|------|
| `-maxdepth 0` | 只对起始目录本身执行操作，不查找其内容 |
| `-maxdepth 1` | 只查找起始目录下的直接内容，**不递归进入子目录** |
| 不写 `-maxdepth` | 无限递归所有子目录 |

注意：`-maxdepth` 是全局选项，最好放在其他测试条件之前，否则可能产生警告或结果不符合预期。

---

### 重点选项 2：`-printf '%T@ %p\n'`

`-printf` 是 **GNU find** 特有的功能（Linux 常见），用于自定义输出格式。  
它不是 POSIX 标准，在 macOS/BSD 的 `find` 中不可用。

格式字符串 `'%T@ %p\n'` 包含三部分：

| 格式符 | 含义 |
|--------|------|
| `%T@`  | 文件最后修改时间的 **Unix 时间戳**（自 1970-01-01 00:00:00 UTC 起的秒数，带小数部分） |
| `%p`   | 文件的路径名（相对或绝对，取决于起始路径） |
| `\n`   | 换行符 |

每个匹配文件输出一行，形如：

```
1672531200.1234567890 /home/user/backup/myapp_20230101.tar.gz
```

#### 关于 `%T@`

- `%T` 是时间格式的引导符，后面可跟不同字母：
  - `%TY`：年
  - `%Tm`：月
  - `%Td`：日
  - `%TH`：时
  - `%TM`：分
  - `%TS`：秒
  - `%T@`：Unix 时间戳（秒 + 小数），不受时区影响
- `@` 表示自 epoch 以来的秒数，包含小数部分（纳秒精度，取决于文件系统）。
- 这种格式非常适合后续用 `sort -n` 按时间排序，或提取时间戳进行计算。

#### 关于 `%p`

- 输出文件的完整路径。
- 如果起始目录是相对路径，`%p` 也是相对路径；如果是绝对路径，`%p` 就是绝对路径。
- 如果只想输出文件名，可以用 `%f`。

---

### 命令执行示例

假设：

- `target_dir=/backup`
- `base_name=myapp`

目录下有：

- `/backup/myapp_20230101.tar.gz`
- `/backup/myapp_20230201.tar.gz`
- `/backup/other_20230101.tar.gz`
- `/backup/subdir/myapp_20230301.tar.gz`

执行命令后，只会找到前两个，输出类似：

```
1672531200.0000000000 /backup/myapp_20230101.tar.gz
1675209600.0000000000 /backup/myapp_20230201.tar.gz
```

子目录中的文件不会被找到，因为 `-maxdepth 1`。

---

### 注意事项

1. **GNU find 专有**：`-printf` 在 BSD/macOS 上不存在，可用 `-exec stat` 替代：
   ```bash
   find ... -exec stat -c '%Y %n' {} \;
   ```
   或 macOS：
   ```bash
   find ... -exec stat -f '%m %N' {} \;
   ```

2. **时间戳精度**：`%T@` 输出的小数位数取决于文件系统，常见为 9 位纳秒。

3. **排序**：如果想按时间从旧到新排序，可以管道给 `sort -n`：
   ```bash
   find ... -printf '%T@ %p\n' | sort -n
   ```

4. **变量引用**：`"$target_dir"` 和 `"${base_name}_*.tar.gz"` 都用了双引号，防止路径含空格或通配符被 shell 提前展开。`-name` 中的 `*` 由 `find` 自己解释，不会传给 shell。

## 三、快速总结

| 主题 | 关键点 |
|------|--------|
| awk `+$5` | 一元加号，强制转数值，等价 `$5 + 0`，避免字符串比较 |

| find `-maxdepth 1` | 只查当前目录，不递归子目录 |
| find `-printf '%T@ %p\n'` | GNU find 专有，输出修改时间戳和完整路径 |
| `%T@` | Unix 时间戳（秒 + 小数） |
| `%p` | 文件路径；`%f` 是文件名 |
