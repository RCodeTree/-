## 第 01 课：Python 环境与基础语法

**① 为什么不能全局 `pip install`？**
全局安装会让不同项目依赖同一套库，A 项目要 `requests 2.0`、B 项目要 `3.0` 就会互相冲突。正确做法是每个项目建独立虚拟环境（venv）隔离依赖，保证可复现。

**② 找出 Shell 和 Python 的 3 个差异**
- 变量引用：Shell 用 `$NAME`，Python 直接用 `name`；
- 类型：Shell 一切皆文本/命令拼接，Python 有 int/str/list/dict 等类型；
- 错误处理：Shell 靠退出码 `$?` 判断，Python 有 try/except 异常机制。
（还可补充：Shell 靠换行/`;` 分隔语句，Python 靠缩进。）

## 第 02 课：os 与 sys

**① 为什么读环境变量要用 `os.environ.get("K", "默认")` 而不是 `os.environ["K"]`？**
`os.environ["K"]` 在键不存在时会抛 `KeyError` 导致脚本崩溃；`.get("K", "默认")` 在键不存在时返回默认值，脚本更健壮。

**② 为什么说“退出码是运维的契约”？举一个场景**
退出码是自动化系统判断成败的契约：Shell 的 `$?`、CI/CD 流水线、K8s 探针都靠它。
- K8s liveness/readiness 探针返回非 0 会被判定为失败并触发重启；
- CI 中测试命令退出码非 0 会使流水线失败并阻止部署。

## 第 03 课：pathlib + shutil

**① `Path("a") / "b"` 比 `"a" + "/" + "b"` 好在哪里？**
- 跨平台：自动使用 `\` 或 `/`，不用手写分隔符；
- 健壮：自动处理多余/重复分隔符；
- 面向对象：返回 `Path` 对象，可直接链式调用 `.exists()` / `.glob()` / `.read_text()`。

**② `shutil.disk_usage` 三个值的单位？怎么换算？**
单位是字节（byte）。`// 1024**3` 得到 GiB（二进制），`// 1000**3` 得到 GB（十进制）。运维里常混用，报告时建议明确标注 GiB/GB。

**③ 为什么 `rmtree` 危险？用之前该先确认什么？**
因为它递归删除整棵目录树、不可恢复（不进回收站）。使用前确认：目标路径绝对正确（防手误删错）、有无备份/快照、是否真的不再需要、生产环境建议加二次确认和审计日志。

## 第 04 课：subprocess

**① 为什么 `shell=True` 危险？写一句可注入的恶意输入示例**
`shell=True` 会把整段字符串交给 shell 解释，用户输入可能被当成命令执行。示例：`user_input = "; rm -rf ~"`，`subprocess.run(f"ls {user_input}", shell=True)` 会执行两条命令。

**② `subprocess.run` 相比 `os.system` 的 3 个优势**
- 结构化拿到 stdout/stderr；
- 直接拿到正确的 returncode（`os.system` 返回值要 `>> 8`）；
- 支持 `timeout` 与 `check` 异常处理。

**③ 列表传参和字符串传参的本质区别？**
列表传参让“命令”和“参数”分离，外部输入不会被 shell 解释为命令；字符串 + shell 则把输入也交给 shell 解析，存在命令注入面。

## 第 05 课：json + yaml

**① 为什么用 `yaml.safe_load` 而不是 `yaml.load`？**
旧版 `yaml.load` 允许反序列化成任意 Python 对象，恶意 YAML 可触发任意代码执行（反序列化漏洞）；`safe_load` 只解析基础数据类型，是安全底线。

**② json 和 yaml 各适合什么场景？举例**
- json：程序/API 之间交换数据（结构化、严格、无注释）；
- yaml：人写的配置（Docker Compose、K8s 清单、CI 文件，可读性好、支持注释）。

**③ `ensure_ascii=False` 的作用？**
让中文等非 ASCII 字符原样输出，而不是转成 `\u4e2d\u6587` 转义码，保持文件可读。

## 第 06 课：re 正则

**① `.*` 和 `.*?` 的区别？提取字段时用哪个？**
`.*` 贪婪匹配（尽量多吃），`.*?` 非贪婪匹配（尽量少吃）。提取字段用非贪婪，否则会跨到最后一个可匹配位置、吃过头。

**② `findall` 正则有多个分组时返回什么？**
返回元组列表 `[(g1, g2, ...), ...]`；无分组时返回字符串列表。

**③ 为什么日志解析推荐命名分组？**
`(?P<name>...)` 让 `groupdict()` 直接产出字典，字段名即语义，利于后续入库、告警和可读性。

## 第 07 课：logging

**① print 和 logging 相比，生产环境为什么用后者？**
logging 有级别（可一键静默）、可多目标输出（文件/网络）、格式统一（带时间/模块/行号）、便于被采集进监控系统。

**② 为什么库/模块代码不该调用 `basicConfig`？**
日志配置是最终使用者的决定权；库若擅自配置会覆盖、污染宿主程序的日志设置。

**③ `RotatingFileHandler` 的 `maxBytes` 和 `backupCount` 分别干什么？**
`maxBytes`：单个日志文件达到该字节数即触发轮转；`backupCount`：保留的旧文件份数，超出则删除最旧的。

## 第 08 课：argparse + datetime

**① 位置参数和可选参数（`--`）的区别？**
位置参数按顺序出现、必填；可选参数以 `--` 为前缀、可设默认值、可省略，且常用 `store_true` 做开关。

**② `strftime` 和 `strptime` 分别代表什么方向？**
`strftime` = format（对象 → 字符串）；`strptime` = parse（字符串 → 对象）。

**③ naive 和 aware 时间对象的区别？何时必须用 aware？**
naive 不含时区信息，aware 含时区。跨时区处理、存库、跨服务通信时必须用 aware（如 `zoneinfo.ZoneInfo`），避免时间歧义。
